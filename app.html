How API Keys & Model Integration Work

Calvras connects directly from your local desktop app to model APIs using low-latency streaming. Your keys are stored only on your machine in encrypted local storage and are never uploaded to any third party. If a provider hits a rate limit, Calvras automatically falls back to your next active key.
